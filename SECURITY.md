# Seguridad

Este paquete solo valida el formato y los dígitos de control de números de documentos; no hace consultas de red ni guarda datos. Aun así, un fallo que cause denegación de servicio (por ejemplo, una expresión regular con retroceso excesivo) o una validación que acepte números que debería rechazar de forma sistemática se trata como un problema de seguridad.

## Cómo reportar

Use el [reporte privado de vulnerabilidades de GitHub](https://github.com/momotombodevs/stdnum-centroamerica/security/advisories/new). No abra un issue público con el detalle.

Se confirma la recepción en unos días y se informa el avance hasta publicar la corrección.

## Versiones con soporte

Solo la última versión menor publicada.
